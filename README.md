# sniffly
(noune) : whonuhhunna?

## what?

sniffly is a disk space analyzer inspired by SpaceSniffer, designed specifically for Unix-based systems, and written entirely in modern Fortran. Visualize your disk usage and quickly identify what's taking up space on your machine.

## features

visual treemap representation of disk usage
fast scanning engine
interactive navigation
toggle dotfiles/hiddens
quick open in finder
quick delete of offending files
native macOS application
